# IssueTracker Backend

Spring Boot backend for a renovation project management application.

## Tech stack
- Java 21
- Spring Boot 3.5.8
- Spring Data JPA
- PostgreSQL
- Flyway
- REST APIs

## Features
- User management
- Project management
- Task/Issue tracking
- Status history

## Architecture
Clean architecture with domain, service, repository and controller layers.
